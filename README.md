# Gunjigavi Hospital Website

A modern, responsive hospital management website built with React and TypeScript.

## Features

- Home Page with hospital information
- Appointment booking system
- Doctors directory
- Hospital services listing
- Contact page
- Admin dashboard
- Responsive design with Tailwind CSS

## Getting Started

### Installation

```bash
cd gunjigavihospital
npm install
npm start
```

## Project Structure

- `src/components/` - Reusable React components
- `src/pages/` - Page components for routing
- `src/types/` - TypeScript type definitions

## Available Scripts

- `npm start` - Run development server
- `npm build` - Build for production
- `npm test` - Run tests

## Tech Stack

- React 19 with TypeScript
- Tailwind CSS
- React Router DOM
- React Hook Form
- Lucide React Icons
